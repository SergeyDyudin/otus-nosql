# Домашнее задание

## DCS

### Цель:
В результате выполнения ДЗ вы развернете отказоустойчивый DCS.


### Описание/Пошаговая инструкция выполнения домашнего задания:
- Разворачиваем кластер Etcd любым способом. Проверяем отказоустойчивость
- Разворачиваем кластер Consul любым способом. Проверяем отказоустойчивость

### Критерии оценки:
- 10 баллов за 1 из кластеров
- 20 баллов за 2 кластера

### Проверим отказоустойчивость

Потушим ноду, которая является лидером
```sh
docker stop etcd1
```

Другая нода стала лидером
```sh
docker exec etcd2 etcdctl --write-out=table endpoint status
```
```sh
+----------------+------------------+---------+---------+-----------+------------+-----------+------------+--------------------+--------+
|    ENDPOINT    |        ID        | VERSION | DB SIZE | IS LEADER | IS LEARNER | RAFT TERM | RAFT INDEX | RAFT APPLIED INDEX | ERRORS |
+----------------+------------------+---------+---------+-----------+------------+-----------+------------+--------------------+--------+
| 127.0.0.1:2379 | d282ac2ce600c1ce |  3.5.15 |   20 kB |      true |      false |         3 |         12 |                 12 |        |
+----------------+------------------+---------+---------+-----------+------------+-----------+------------+--------------------+--------+
```

Попробуем записать данные
```sh
docker exec etcd2 etcdctl put test "TEST1"
```
Запись продолжается
```
OK
```

Прочитаем данные
```sh
docker exec etcd2 etcdctl get test
```
Чтение продолжается
```  
test
TEST1
```
