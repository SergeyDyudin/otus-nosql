# Домашнее задание

## Работа с tarantool

### Цель:
настроить базовое взаимодействие с Tarantool для хранения и выборки данных, используя индексы и встроенные функции.


### Описание/Пошаговая инструкция выполнения домашнего задания:
- Установите Tarantool одним из доступных способов: через виртуальную машину (ВМ) или Docker.
- Создайте в Box спейс (таблицу) для хранения данных о поисках авиабилетов с полями:
id (уникальный идентификатор),
airline (авиакомпания),
departure_date (дата вылета),
departure_city (город вылета),
arrival_city (город прилета),
min_price (минимальная стоимость авиабилета).
- Добавьте первичный индекс для спейса.
- Создайте вторичный индекс на поля departure_date, airline и departure_city.
- Вставьте несколько записей в спейс.
- Напишите запрос для выборки минимальной стоимости авиабилета на рейсы с датой вылета 01.01.2025.
- Реализуйте функцию на Lua для вывода списка рейсов с минимальной стоимостью билета менее 3000 рублей.


### Критерии оценки:
Задание считается выполненным, если Tarantool установлен, спейс и индексы созданы, данные вставлены, запросы и Lua-функция выполнены, а команды и результаты предоставлены.


# Отчет

### Запуск Tarantool

Запуск производится через docker-compose [файл](../tarantool/docker-compose.yaml).

```sh
docker-compose -f tarantool/docker-compose.yaml up -d
```

Подключение к контейнеру через console:

```sh
docker exec -it tarantool console
```

### Lua-функция

Создание функции для вывода списка рейсов с минимальной стоимостью билета менее 3000 рублей:

```lua
function get_flights_under_price(max_price)
    local result = {}
    for _, tuple in box.space.flights:pairs() do
        local t = tuple:totable()
        if t[6] < max_price then
            table.insert(result, t)
        end
    end
    return result
end
```

Вызов функции:

```lua
get_flights_under_price(3000)
```
